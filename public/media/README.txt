Put your own files here, then point to them from src/content.ts.

  Hero photo       ->  /media/hero.jpg          (wide, subject on the right)
  About photo      ->  /media/jovan.jpg         (5:4)
  Showreel video   ->  /media/showreel.mp4
  Project stills   ->  /media/night-drive.jpg   (16:9)

Anything in the public folder is served from the site root, so
public/media/showreel.mp4 is used in code as "/media/showreel.mp4".
